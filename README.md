# 🤖 Spike Trade Analyzer Bot

Telegram бот для технического анализа торговых сигналов на OTC рынках.

## ✨ ВОЗМОЖНОСТИ

### 📊 Технический Анализ
- **RSI Analysis** - анализ перекупленности/перепроданности
- **MACD Status** - анализ дивергенций и тренда
- **Moving Average** - анализ движущих средних
- **Volatility Scan** - сканирование волатильности

### 🎯 Четкие Сигналы
- 🟢 **BUY** - сигнал к покупке
- 🔴 **SELL** - сигнал к продаже
- 🟡 **HOLD** - удержание позиции

### ⏱️ Гибкие Таймфреймы
- 5 секунд
- 15 секунд
- 30 секунд
- 1 минута
- 2 минуты
- 3 минуты
- 5 минут
- 10 минут

### 📈 Дополнительно
- ✅ Уровень уверенности сигнала (%)
- ✅ Генерация сигналов (%)
- ✅ Сила сигнала (Strong/Moderate/Weak)
- ✅ Временные метки анализа

## 🚀 БЫСТРЫЙ СТАРТ

### Требования
- Node.js 18+
- Telegram Bot Token (от @BotFather)
- Аккаунт Render для хостинга

### Установка локально

```bash
# 1. Клонируйте репо
git clone https://github.com/ваш_юзер/spike-trade-bot.git
cd spike-trade-bot

# 2. Установите зависимости
npm install

# 3. Создайте .env файл
echo "BOT_TOKEN=ваш_токен_здесь" > .env

# 4. Запустите бота
npm start
```

### Развертывание на Render

Смотрите `DEPLOYMENT.md` для пошаговых инструкций.

**Кратко:**
1. Получите токен от @BotFather
2. Загрузьте код на GitHub
3. Создайте Web Service на Render
4. Установите переменную `BOT_TOKEN`
5. Готово! ✅

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### Бот не отвечает

**Проверьте:**
- [ ] Токен установлен правильно в переменных окружения
- [ ] Сервис запущен на Render (статус "Live")
- [ ] Логи не содержат ошибок

**Решение:**
```bash
# Перезагрузите сервис
# На Render: нажмите "Manual Deploy"
```

### Ошибка "Module not found: telegraf"

**Решение:**
- Убедитесь что `package.json` содержит правильные зависимости
- Проверьте что build command содержит `npm install`
- Перезагрузите сервис

### Неправильный токен

```
Error: 401 Unauthorized
```

**Решение:**
1. Откройте @BotFather в Telegram
2. Выберите вашего бота
3. Получите новый токен
4. Обновите переменную `BOT_TOKEN` на Render
5. Перезагрузите сервис
